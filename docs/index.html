Quick Start

The public read endpoints need no API key. Use the deployed base URL below, or replace it with your own deployment. 

curl "https://indonesia-holiday-api.onrender.com/holidays?year=2026"

curl "https://indonesia-holiday-api.onrender.com/holidays?type=CUTI_BERSAMA"

curl "https://indonesia-holiday-api.onrender.com/health"

What You Get

The API returns normalized holiday rows designed for calendars, scheduling tools, HR systems, and internal business apps.

Normalized Dates

Every holiday uses ISO date format, so clients can sort, filter, and display records without extra parsing.

Explicit Types

Records are classified as either national public holidays or cuti bersama using a stable enum.

Automated Updates

A yearly GitHub Actions workflow refreshes holiday data and removes records older than the retention window.

Endpoints

These are the primary routes exposed by the API. Use the Swagger tester below for interactive requests.

GET
/health

Returns a simple health-check response.

GET
/holidays

Returns all stored holidays, sorted by date and type.

GET
/holidays?year=2026

Filters holiday data to a specific year.

GET
/holidays?type=CUTI_BERSAMA

Filters by holiday type. Accepted values are PUBLIC_HOLIDAY and CUTI_BERSAMA.

Response Shape

Holiday responses include the database ID, normalized date, display name, enum type, year, and timestamps. 

[
  {
    "id": "4ab81aa3-2b20-4c7d-b2ea-60236c133f50",
    "date": "2026-01-01",
    "name": "Tahun Baru 2026 Masehi",
    "type": "PUBLIC_HOLIDAY",
    "year": 2026,
    "createdAt": "2026-05-04T02:00:00.000Z",
    "updatedAt": "2026-05-04T02:00:00.000Z"
  }
]
